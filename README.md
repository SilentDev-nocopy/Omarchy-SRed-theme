# Omarchy SRed Theme

A dark Omarchy theme focused on black, charcoal, grey, and deep burgundy / dark red.

## Palette

| Role | Color |
|---|---|
| Background | `#0A090A` |
| Deep background | `#060506` |
| Surface | `#191719` |
| Selection | `#3A2028` |
| Accent | `#7D1F32` |
| Main text | `#D0CACE` |
| Muted text | `#777176` |
| Dark red | `#8F263B` |
| Bright red | `#B83B52` |

## Install

Install this repository using Omarchy's theme installer if supported by your installed version, or copy the theme into your user themes directory:

```bash
mkdir -p ~/.config/omarchy/themes/s-red
cp colors.toml ~/.config/omarchy/themes/s-red/
cp -r backgrounds ~/.config/omarchy/themes/s-red/
omarchy theme set s-red
```

Run the copy commands from the repository root. Add wallpapers you own or are licensed to redistribute to `backgrounds/`.

## Notes

The palette uses Omarchy's semantic color keys. Individual applications may need their own theme configuration if they do not follow Omarchy's generated colors.
